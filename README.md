# ◈ Noventra Signal Mini App

TON / DeDust odaklı sinyal ve alarm Mini App'i.

## Özellikler

### Piyasa
- Yükselen / Düşen / Hacim / Sinyal sekmeleri
- 5dk · 1s · 6s · 24s değişimler
- GÜÇLÜ AL / AL / SAT / GÜÇLÜ SAT etiketleri
- Momentum skoru
- DeDust & Ston.fi ayrımı

### Favoriler (kalıcı)
- ★ ile favori ekle / çıkar
- localStorage ile saklanır
- Favoriler sekmesinden takip et

### Alarmlar
- 🔔 ile alarm kur
- Yüzde yükselince / düşünce
- Fiyat üstüne / altına
- Tetiklenince üstte banner + titreşim
- Alarmlar sekmesinden yönet

### Tasarım
- Koyu-mavi premium tema
- Telegram temasına uyumlu
- Alt navigasyon

## Kurulum

1. `index.html` dosyasını GitHub Pages / Netlify / Vercel'e yükle
2. BotFather → Menu Button → URL yapıştır
3. Telegram'dan aç

## Not

Yatırım tavsiyesi değildir. Sadece bilgilendirme amaçlıdır.
